# EMS Microservices

Enterprise Employee Management System built using Spring Boot Microservices.

## Tech Stack

- Java 21
- Spring Boot
- Spring Cloud
- Spring Cloud Gateway
- Eureka Server
- Config Server
- Kafka
- MySQL
- Maven
- Docker (Upcoming)

## Microservices

- API Gateway
- Service Registry
- Config Server
- Employee Service
- Department Service
- Notification Service

## Project Structure

ems-microservices/
├── api-gateway
├── config-server
├── service-registry
├── employee-service
├── department-service
├── notification-service

## How to Run

1. Start Config Server
2. Start Eureka Server
3. Start all Microservices
4. Start API Gateway
